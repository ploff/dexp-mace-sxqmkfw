# Подсветка DEXP Mace (RKGK890)

В прошивке `v0.3` подсветка управляется через QMK RGB Matrix и
повторяет девятнадцать режимов оригинальной клавиатуры. Режимы включаются
с клавиатуры, без драйвера.

## Управление

| Комбинация | Действие |
|---|---|
| `Fn+Scroll Lock` | следующий режим подсветки (19 режимов) |
| `Fn+Home` | следующий цвет: белый, красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый |
| `Fn+↑` / `Fn+↓` | яркость + / − |
| `Fn+←` / `Fn+→` | скорость эффекта − / + |
| `Fn+W` | поменять `WASD` местами со стрелками (сохраняется в EEPROM) |
| `Fn+Esc` | вход в бутлоадер |

Яркость, скорость, цвет и режим сохраняются в EEPROM. Для полного сброса
настроек можно использовать `EE_CLR` в собственной раскладке или
перепрошить клавиатуру с очисткой EEPROM.

## Режимы

Порядок соответствует оригинальному списку из драйвера HFD:

| № | Режим | Название в драйвере |
|---:|---|---|
| 1 | Static | Статичный режим |
| 2 | SingleOn | Подсветка клавиши при нажатии |
| 3 | SingleOff | Затемнение клавиши при нажатии |
| 4 | Glittering | Искрение |
| 5 | Falling | Падающий снег |
| 6 | Colourful | Разноцветная |
| 7 | Breath | Дыхание |
| 8 | Spectrum | Радуга |
| 9 | Outward | От центра к краям |
| 10 | Scrolling | Сверху вниз |
| 11 | Rolling | Волна |
| 12 | Rotating | Циркуляция |
| 13 | Explode | Взрыв |
| 14 | Launch | Пуск |
| 15 | Ripples | Волна при нажатии |
| 16 | Flowing | Течение |
| 17 | Pulsating | Пульсация |
| 18 | Tilt | Под косым углом |
| 19 | Shuttle | Движение туда-обратно |

Дополнительно в цикл добавлен `Off` (полное выключение). В оригинальной
инструкции указано 19 режимов; `Off` просто удобен для быстрого
выключения подсветки.

## Как это устроено

- 6 строк подсветки, по три канала на строку — 18 строковых пинов;
- 17 общих колонок с клавиатурной матрицей: `C12…C0`, `C15`, `B15`,
  `B13`, `B12`;
- строки — низковольтные ключи `J3Y` (S8050, NPN), колонки — `QX`
  (`2TY`, S8550, PNP);
- `SOFTWARE_PWM` обязателен: на колонках `B12/B13/B15` нет аппаратного
  ШИМ, без софтверного правый блок не горит;
- порядок в массиве — **R, B, G** (так ожидает драйвер `sn32f2xx`).

Финальная карта (проверена на живой плате):

| Ряд | Ноги U4 | QMK |
|---|---|---|
| F | 25, 26, 27 | A8, A9, A10 |
| цифры | 28, 29, 30 | A11, A12, A13 |
| QWERTY | 31, 32, 34 | A14, A15, B0 |
| ASDF | 35, 36, 37 | B1, B2, B3 |
| ZXCV | 38, 39, 41 | B4, B7, B5 |
| нижний | 51, 48, 44 | D3, B14, B10 |

```c
#define SN32F2XX_RGB_MATRIX_ROW_PINS \
    { A8, A9, A10, A11, A12, A13, A14, A15, B0, B1, B2, B3, B4, B7, B5, D3, B14, B10 }

#define SN32F2XX_RGB_MATRIX_ROWS 6
#define SN32F2XX_RGB_MATRIX_COLS 17
#define SN32F2XX_PWM_CONTROL SOFTWARE_PWM

/* Невыбранные строки матрицы прижаты к высокому уровню, чтобы нажатая
 * клавиша не могла утянуть общую колонку вниз и открыть PNP-ключ. */
#define MATRIX_UNSELECT_DRIVE_HIGH
```

Пропуски в нумерации ног объясняются занятыми линиями: 33 — `VDD`,
40–44 — RF-модуль, 46–47 — колонки матрицы (`B12/B13`), 49 — строка
матрицы (`D9`), 50 — колонка (`B15`).

## Артефакт «столбец при нажатии»

В `v0.2` при нажатии клавиши весь её столбец вспыхивал на полной
яркости. Причина — общие колонки: нажатая клавиша соединяет колонку со
строкой матрицы, открывая PNP-ключ колонки в обход ШИМ; при этом драйвер
оставлял колонки в `input` без подтяжки.

Исправлено двумя правками:

1. `drivers/led/sn32f2xx.c`: во время скана колонки переводятся в
   `gpio_set_pin_input_high` (input с подтяжкой), а не в floating input.
2. `config.h`: `MATRIX_UNSELECT_DRIVE_HIGH` — невыбранные строки матрицы
   жёстко прижаты к высокому уровню.

Патч драйвера: `qmk/patches/0001-sn32f2xx-shared-matrix.patch`.

## Известные проблемы

- Индикаторы `Caps Lock` / `Scroll Lock` / `Win Lock` пока горят вместе с
  подсветкой: это отдельные одноцветные светодиоды, их управляющие ноги
  ещё не разведены в QMK.
- VIA и дополнительные слои не настроены.
